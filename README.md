### 🚌 Smart Bus System (The "Where's My Bus?" Solver)
[📂 Check it out](https://github.com/NgKhai/Bus-System-Management-v2.0)

Remember waiting forever for the bus? Yeah, me too. So I built this:
- **Face recognition** for attendance (because QR codes are so 2020)
- **Real-time tracking** - never miss your ride again!
- Works on both **mobile** and **web** platforms

*Built with love and lots of coffee using Flutter, Python Flask, Firebase & OpenCV*
